# Chrome 浏览器控制 (bctl)

本机已安装全局 CLI `bctl`，用于驱动用户日常正在使用的 Chrome 浏览器（全复用当前 Cookie、登录态、密码与已打开会话）。

## 核心设计：双人并发与后台多标签隔离

为了保证**人类用户在前台自由浏览其他网页，大模型在后台静默操作，互不干扰**：

1. **若需要打开新网页自动化**：
   - 使用 `bctl new <url>`：Chrome 会在**后台静默创建标签页**并自动绑定，人类当前正在看的标签页**绝对不会被切换或夺取焦点**！
2. **若需要接管已打开的网页或 JumpServer 终端**：
   - 先执行 `bctl tabs` 查看标签页列表。
   - 再执行 `bctl bind <关键词|TabID>`（例如 `bctl bind jumpserver` 或 `bctl bind github`）锁定后台目标。
3. 绑定后，大模型调用的所有 `exec`、`look`、`act`、`open` 均在绑定的后台标签页独立运行，**前台人类输入与鼠标完全不受任何干扰**。
4. 在受控标签页中，页面正上方会浮现 `[AI Agent 正在控制此标签页]` 状态胶囊，中心呈现 ChatGPT 官方同款原生光标，并以**弹簧阻尼动力学模型（Spring Physics）**呈现极其丝滑的贝塞尔曲线鼠标移动与打字机输入。

## 常用命令一览

| 场景 | 命令 | 说明 |
| :--- | :--- | :--- |
| **后台静默打开网址** | `bctl new "<url>"` | **强烈推荐**：在后台新建 Tab 并自动绑定，前台人类视角 0 干扰 |
| **列出所有标签页** | `bctl tabs` | 查看 Chrome 当前所有打开的标签页（含 TabID、标题、URL、绑定状态） |
| **绑定后台标签页** | `bctl bind <关键词|TabID>` | 锁定目标 Tab 并关闭后台休眠，后续命令全在后台静默执行 |
| **JumpServer 命令执行** | `bctl exec "<shell命令>"` | 穿透 JumpServer (Koko) xterm 终端执行命令并返回干净的标准输出 |
| **观察页面元素** | `bctl look` | 在绑定的目标页面打上可视编号，返回 `[0]`, `[1]`... 紧凑结构摘要 |
| **执行鼠标/键盘动作** | `bctl act '<JSON动作数组>'` | 驱动动作（点击/输入/滚动等），滚动支持 `{"type":"scroll","deltaY":500}` |
| **在当前绑定页跳转** | `bctl open "<url>"` | 在已绑定的标签页中打开新网址并返回页面摘要 |
| **解除控制恢复标签页** | `bctl unbind` (或 `release`) | 解除当前标签页控制，立即平滑淡出胶囊并复原原生 Tab 栏图标与标题 |
| **重载扩展** | `bctl reload` | 热重载 Chrome 扩展代码与 Content Scripts |
| **状态检查** | `bctl status` | 检查 Chrome 扩展连接与守护进程状态 |

## 通用页面操作原则

- **按页面状态操作。** `bctl look` 是元素摘要，列出的 input 也可能处于收起或遮挡状态。输入前确认控件已展开、可见且可编辑；需要展开、打开或激活的控件，先触发入口，观察状态变化后再操作。
- **目标定位有依据。** 使用当前页面的标签、语义和位置确认目标，不猜无标签元素或沿用旧编号。摘要无法区分目标时，补充浏览器截图或可访问性信息；坐标点击依据当前截图定位。
- **以页面结果判断成功。** 工具报告“点击成功”或“输入成功”仅表示动作已执行。检查与任务对应的页面变化，例如出现搜索结果、展开菜单或进入目标详情，再继续依赖该结果的操作。
- **异常后重新观察。** 页面未发生预期变化时，先检查目标、控件状态和实际反馈，再调整操作；不要重复同一动作或继续操作无关元素。区分工具连接错误与网站自身错误，不凭工具报错推断网站状态。
- **在状态边界拆分动作。** 对已确认的控件可批量执行输入与提交；展开控件、导航或异步加载后，读取新状态再决定下一步。常规交互遵循这些原则，站点专用说明只记录无法从页面推断的机制或已验证的特殊限制。

## 控制权生命周期准则（优先方案 A + 10 分钟兜底）

1. **任务完成规范（优先方案 A）**：大模型完成所有网页操作后，**必须在最后调用 `bctl unbind`**，立即归还正常标签页环境。
2. **10 分钟超时兜底（方案 B）**：若大模型意外断流、中断或遗漏调用，后台将在 **10 分钟** 无操作后自动解绑并恢复，普通推理规划期间绝不提前淡出或闪烁。
3. **人类主动接管**：人类随时点击进入该 Tab 或在页面上点击鼠标，控制态即刻解除。

## JumpServer Web 终端

登录态未知时先从站点主入口完成认证，再进入 Web 终端（Luna）；直接访问 `/luna/` 可能在认证失效时反复重定向。只有当前会话已显示登录后的主界面，或现有终端可正常执行命令，才可直接进入 Luna；发生重定向循环时返回主入口重新认证。

按通用页面操作原则选择并连接目标服务器。连接完成后使用 `bctl exec "<shell命令>"` 执行命令并读取输出。

### 终端命令可读性与审计红线（强制规范）

1. **严禁加密或编码命令**：严禁将命令或配置内容通过 `base64`（如 `echo ... | base64 -d`）、十六进制、压缩混淆等任何人类无法直接阅读的方式下发执行。
2. **全程明文可读**：所有在终端执行的命令、修改或写入的配置文件（如使用 `cat << 'EOF' > ...`、`sed` 等），必须是人类可直接阅读的明文，方便用户实时观察学习与事后安全审计。
3. **禁止附加多余标记**：直接下发纯净的原始命令，严禁手动拼接如 `BCTL_S_` / `BCTL_E_` 等起止探测标记。
